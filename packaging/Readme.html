Finish setup in Terminal

Use this command to sign your installed copy locally and remove its download quarantine before opening it. This build is ad-hoc signed, not notarized.

  1. Copy the app to Applications first, then quit it if it’s running.
  2. Open the Terminal shortcut in the disk image, or find Terminal in Applications → Utilities.
  3. Click Copy command, paste into Terminal with ⌘V, and press Return.
  4. Wait for “Ready,” then open Meta Quest Virtual Display from Applications.
Terminal · zsh
View the command
(
  set -eu
  quest_app="/Applications/Meta Quest Virtual Display.app"
  if [ "$(/usr/libexec/PlistBuddy -c 'Print :CFBundleIdentifier' "$quest_app/Contents/Info.plist")" != "io.github.quest-vd-mac-usb" ]; then
    echo "Copy the app from this DMG to Applications first."
    exit 1
  fi
  /usr/bin/codesign --verify --deep --strict "$quest_app"
  /usr/bin/codesign --force --deep --sign - "$quest_app"
  /usr/bin/codesign --verify --deep --strict "$quest_app"
  /usr/bin/xattr -dr com.apple.quarantine "$quest_app"
  echo "Ready. Open Meta Quest Virtual Display from Applications."
)

You can also expand the command and select it to copy manually.

What it does. Removes quarantine and self-signs only the installed Meta Quest Virtual Display app. It checks the app’s identity and existing signature first and leaves global macOS security settings unchanged.

All set? Eject the disk image. Your installed app stays in Applications.

Connect your Quest with a USB data cable and choose your Mac’s USB entry. For updates, sync your fork and run Build DMG again.
