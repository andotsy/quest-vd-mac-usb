# Distribution

The public repository contains our patch source. Builds run in your fork or copy and produce a temporary DMG artifact, not a Release.

**Forking doesn’t grant redistribution rights.** Meta’s app remains proprietary; its terms restrict modification and distribution, subject to applicable law. This workflow isn’t legal clearance.

Public-repository artifacts are downloadable by other signed-in users with read access. Use a **private repository copy** to restrict access; GitHub doesn’t allow private forks of public repositories. Privacy doesn’t change Meta’s terms.
